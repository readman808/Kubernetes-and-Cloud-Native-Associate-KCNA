# Solr Incident Room

Two standalone HTML files. No install or server needed: open them in any browser.

- `solr-troubleshooting.html`: simulator with six Solr-on-Kubernetes incidents. Type kubectl and Solr API commands to fix each one.
- `solr-runbook.html`: companion runbook with concepts, a method and step-by-step procedures.

Keep both files in the same folder so the links between them work. Fonts load from Google Fonts when online and fall back to system fonts offline.
